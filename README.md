## Update GitHub Pages

1. Back up your current repository files.
2. Extract this package on your computer.
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the root of your `zahid11280.github.io` repository. Replace the matching existing files.
4. Commit the changes. Keep your existing GitHub Pages branch/folder configuration.
5. After the deployment completes, refresh the portfolio with Ctrl+Shift+R.

No build command or package installation is needed. Open `index.html` to preview locally. Fonts are loaded from Google Fonts with system fallbacks.
